| 이런 분께

연습은 하는데, 왜 그대로일까요

네. 그립온 스타트 클래스는 클럽과 장비 사용법부터 시작하는 완전 입문자용 과정입니다. 전문 용어보다 직접 해본 경험으로 이해하도록 가르칩니다.

영상으로 본인 스윙을 직접 보고 힘 빼는 구간과 힘주는 구간을 구분하는 방식이라, 감각적으로 다시 짚어드립니다. 기존 레슨과 접근 자체가 다릅니다.

한국골프협회 티칭프로 자격을 보유한 송세환 코치가 직접 지도합니다. 수업이 끝나면 다음에 혼자 연습할 한 가지만 정리해 전달합니다.

  • 힘 빼는 법
    모든 클래스의 기본

  • 어드레스
    매번 같은 기준

  • 영상 피드백
    직접 보고 확인

  • 1개월 단위
    목표별 5개 과정
